| Файл | Что это |
|---|---|

На с. 2 — карта критериев оценки |

## Перед подачей

1. Впишите участников, телефон, e-mail и ссылку на репозиторий в `team.json`; незаполненные поля выводятся янтарным в квадратных скобках.
2. Пересоберите: `node build_submission.js assets InvaRadar_Ecopremia2026_podacha.pptx`, затем PDF (PowerPoint: Файл → Экспорт → PDF, или `soffice --headless --convert-to pdf …`). Когда ссылка на репозиторий заполнена, на с. 10 появляется QR-код.
3. Проверьте: 10 страниц A4, ни одного поля в квадратных скобках; размер файла — в пределах лимита формы на ecopremia.moscow (на 30.10.2026 — 30 МБ на файл, архивы не принимаются).

## Перед показом полной версии

1. Установите шрифты: Windows — `fonts/install_fonts_windows.ps1`, macOS и Linux — `fonts/install_fonts.sh`.
2. Откройте PPTX в PowerPoint и сохраните со встроенными шрифтами: Файл → Параметры → Сохранение → «Внедрить шрифты в файл» → «Внедрять все символы». После этого файл можно открывать на любом компьютере.
3. Команда и контакты на слайде 20 берутся из `team.json`.

## Дизайн

- **Идея:** гербарий и топографическая карта. Тёмный лесной зелёный — фон ключевых слайдов, бумажный светлый — рабочие слайды, янтарный — предупреждение (фототоксичный сок борщевика), ржавый — очаги, золотой — золотарник, синий — вода.
- **Шрифты:** Literata для заголовков и латинских названий видов (книжная антиква с греческим алфавитом для формул), Golos Text для текста (гротеск ParaType, созданный для портала госуслуг), JetBrains Mono для подписей, координат и данных.
- **Декор из данных проекта:** горизонтали по рельефу Москвы из нашей ЦМР, штриховой рисунок сложного зонтика, иконки Tabler в тонком штрихе.
- **Фото:** реальные наблюдения iNaturalist под CC BY и CC0 с указанием авторов на слайдах; вставляются функцией `photo()` с исходными пропорциями — лишнее обрезается, а не растягивается. Сгенерированные изображения растений не используются: ботаник в жюри заметит неточности морфологии, а реальные снимки — это доказательство.
- **Графики:** нативные графики PowerPoint, их можно править и проверять по данным.

## Пересборка

```bash
cd presentation
npm ci
python fetch_photos.py        # фото из iNaturalist open data
python make_decor.py          # горизонтали, зонтик, градиенты (нужен data/dem_10m.tif)
python prepare_assets.py      # научные рисунки из outputs/figures
npm run icons                 # иконки (нужен Playwright)
npm run build                 # InvaRadar_Ecopremia2026.pptx
node build_submission.js assets InvaRadar_Ecopremia2026_podacha.pptx
python export_notes.py InvaRadar_Ecopremia2026.pptx SPEAKER_NOTES.md
```
