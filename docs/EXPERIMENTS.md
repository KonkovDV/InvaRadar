# Журнал экспериментов и решений

Каждое решение в ИнваРадаре принято по заранее заданному критерию на данных, которых модель не видела. Здесь — что сравнивали, на чём, с каким результатом и что оставили. Числа берутся из `outputs/`; команда воспроизведения — в последнем столбце.

## Протокол

- **Карта.** Прогон 6.11.2026: шахматка блоков 5 × 5 км и полоса 500 м вокруг проверочных присутствий, шире окна 450 м. Разрез по году метки: обучение на находках до 2024 года, проверка на находках 2025–2026 годов дальше 500 м от старых (216 из 504 и 188 из 446). Признаки — эмбеддинг AlphaEarth 2025 года, тот же снимок. Это не прогноз с изображения 2024 года. Прогон с флагом `--embedding-year 2024` записан в `outputs/variants/*_retro2024/`. Пиксельная версия на 64 каналах остаётся в `pro/analysis/results/TABLES.md`. Основной доклад по карте — доля находок в верхних 10% площади. Для рельефа критерий задан отдельно: доля новых мест в верхних 20%. 95% интервалы — бутстрэп по блокам, 2000 повторов, и интервал Уилсона для разреза по году.
- **Модуль БПЛА.** Открытый набор Сколтеха: 263 аэрофото Подмосковья, три камеры [47]. Камера проверки целиком исключается из обучения. Порог читается с вневыборочных оценок остальных камер. Эти числа записаны в `outputs/drone/benchmark.json`.
- **Фото жителей.** 13 000 снимков, 5 фолдов по наблюдателям: снимки одного автора не попадают одновременно в обучение и проверку.
- **Правило выбора.** Критерий фиксируется до сравнения. Для рельефа это доля новых мест в верхних 20% площади.

## Модуль БПЛА на реальных аэрофото

| № | Вопрос | Варианты | Критерий | Результат | Решение | Воспроизведение |
|---|---|---|---|---|---|---|
| E-08 | Чем сегментировать листья и розетки | замороженный DINOv2 ViT-S/14 + линейный классификатор по патчу / то же + среднее по окрестности 3 × 3 | ROC AUC и AP по патчам, камера исключена | В `outputs/drone/benchmark.json` сохранён вариант с окрестностью: ROC AUC **0,948**, AP **0,747**. Сравнение без окрестности (0,946 / 0,735) в репозитории не сохранено | с окрестностью | `make drone` |
| E-09 | Рабочая точка | max F1 (баланс) / max F2 (разведка: пропуск дороже лишней проверки) | порог с других камер, не с той, которую докладывают | F1: Dice 0,722, полнота 74,5%, 221 из 251, пустые чистые 9 из 12. **F2: Dice 0,636, полнота 92,2%, 245 из 251, пустой чистый 1 из 12.** Прежний файл давал F2 Dice 0,71 и 216 из 251: порог был снят с тех же кадров | F2 для разведки, F1 — для подсчёта площади. Цена F2 — почти все пустые кадры | `outputs/drone/benchmark.json` |

По камерам (F2, порог с остальных): Mavic Pro — ROC AUC 0,952, Dice 0,468; Phantom 3 — 0,968 и 0,705; Xiaomi Yi — 0,962 и 0,699. У Mavic порог опустился до 0,10. Для сравнения: авторы набора сообщают для своей бортовой сети ROC AUC 0,96 [40]; у ИнваРадара — 0,95 при проверке, в которой камера снимка не встречалась в обучении.

Бэкенд лицензирован под Apache-2.0 (DINOv2), поэтому годится для муниципального внедрения. Для цветущих куртин остаётся безобучающий индекс цветения (`BloomIndexSegmenter`); на этом наборе снимки весенние, без зонтиков, поэтому он не сравнивается.
