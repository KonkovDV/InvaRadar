| Файл | Что это |
|---|---|

На с. 2 — карта критериев оценки |

## Дизайн

- **Идея:** гербарий и топографическая карта. Тёмный лесной зелёный — фон ключевых слайдов, бумажный светлый — рабочие слайды, янтарный — предупреждение (фототоксичный сок борщевика), ржавый — очаги, золотой — золотарник, синий — вода.
- **Шрифты:** Literata для заголовков и латинских названий видов (книжная антиква с греческим алфавитом для формул), Golos Text для текста (гротеск ParaType, созданный для портала госуслуг), JetBrains Mono для подписей, координат и данных.
- **Декор из данных проекта:** горизонтали по рельефу Москвы из нашей ЦМР, штриховой рисунок сложного зонтика, иконки Tabler в тонком штрихе.
- **Фото:** наблюдения iNaturalist под CC BY и CC0. Авторы указаны на слайдах и в `assets/CREDITS.csv`. Кадр сохраняет пропорции файла: лишнее обрезается.
- **Графики:** нативные графики PowerPoint, их можно править и проверять по данным.

## Пересборка

```bash
cd presentation
npm ci
python fetch_photos.py        # фото из iNaturalist open data
python make_decor.py          # горизонтали, зонтик, градиенты (нужен data/dem_10m.tif)
python prepare_assets.py      # научные рисунки из outputs/figures
npm run icons                 # иконки (нужен Playwright)
npm run build                 # InvaRadar_Ecopremia2026.pptx
node build_submission.js assets InvaRadar_Ecopremia2026_podacha.pptx
python export_notes.py InvaRadar_Ecopremia2026.pptx SPEAKER_NOTES.md
```
