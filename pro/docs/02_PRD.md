# Требования к продукту (PRD)

## 1. Цель

Цель продукта — довести очаг инвазивного растения от сигнала до закрытия. Метод работ разрешён законом, работа доказана, повторы выполнены, а каждый шаг записан в журнал, который нельзя незаметно исправить.

## 2. Пользователи и их задачи

| Роль | Задача («когда…, хочу…, чтобы…») |
|---|---|
| Инспектор округа или префектуры | Когда приходит сигнал, хочу видеть проверенный очаг, законный метод и правовое основание, чтобы утвердить наряд за минуты, а не за дни |
| Диспетчер, руководитель программы | Хочу видеть очередь по пользе и ёмкости бригад, просрочки и KPI, чтобы отчитаться региону цифрами |
| Юрист | Когда юрисдикция неясна, хочу получать только спорные наряды и оставлять решение со ссылкой |
| Подрядчик | Хочу снимать доказательства в приложении и получать приёмку без споров, чтобы мне платили за сделанное |
| Обладатель сервитута (ЛЭП, дорога, ж/д) | Хочу знать, на каких километрах очаги в охранной зоне, чтобы выполнить обязанность до проверки |
| Житель | Хочу отправить фото и видеть, что по нему сделано |
| Ботаник, «Инвазиум» | Хочу проверять спорные фото и получать данные для науки |
| ИИ-агент | Готовит черновики, назначает осмотры, отвечает на вопросы по закону. Не подписывает |

## 3. Объём MVP к маю 2027 года

| № | Функция | Критерий приёмки (дано → когда → тогда) | Статус |
|---|---|---|---|
| F1 | Импорт кандидатов InvaRadar | Дан `work_orders_top200` → импорт → каждый очаг заведён сигналом с рангом и координатами | готово (`upstream.py`) |
| F2 | Закон в наряде | Дан очаг в водоохранной зоне → решение → все методы с пестицидами запрещены со ссылкой на ВК РФ ст. 65 | готово (`law.py`, тесты) |
| F3 | Отказ в безопасную сторону | Неизвестен слой воды или детей → решение → пестициды запрещены, флаг `context_incomplete` | готово |
| F4 | Шлюз юриста | Юрисдикция не определена или пакет не сверен → утвердить нельзя, пока юрист не снимет вопрос со ссылкой | готово |
| F5 | Подпись человека | Агент или система пытается утвердить или принять → отказ, попытка в журнале | готово |
| F6 | Приёмка по доказательствам | Фото не с места, вне срока или повтор с другого очага → вердикт «fail» → принять нельзя без письменной причины | готово (`evidence.py`) |
| F7 | Запрещённый метод | Подрядчик сдаёт работу запрещённым методом → отказ, попытка в журнале | готово |
| F8 | Повторы и закрытие | Принята работа → график контроля; рецидив → снова в работу; закрытие только после 3 или 5 чистых сезонов | готово |
| F9 | Журнал | Любая правка задним числом → проверка показывает первое испорченное событие | готово (`events.py`) |
| F10 | Паспорт очага | Для любого очага → Markdown или веб: закон, требования, журнал с хешами | готово (`report.py`) |
| F11 | KPI | Из журнала, без ручного ввода | готово (`kpi.py`) |
| F12 | Аудит коридора | Дана линия и напряжение → километры с очагами, площадь в охранной зоне | готово (`corridor.py`) |
| F13 | Полевая выборка | Даны слои и ответы → доля, точность, полнота с интервалами | готово (`sampling.py`) |
| F14 | Бот для жителей | Фото → ИИ-проверка вида (≥ 0,9 — автоподтверждение) → статус | план (декабрь) |
| F15 | Приложение подрядчика | Съёмка с временем и местом от сервера, код наряда в кадре | план (январь – февраль) |
| F16 | Веб-интерфейс | Карта очагов, очередь, паспорта, подпись наряда | план (декабрь – январь) |
| F17 | Импорт обращений | «Добродел», «Наш город», «Инвазиум», контуры Яндекса | план (февраль – март) |
| F18 | Ретро-прогноз | Ранжирование новых мест на эмбеддинге прошлого года | план (ноябрь) |

## 4. Нефункциональные требования

- **Данные в РФ.** Облако в России (Yandex Cloud — партнёр Академии, грант 400 тыс. ₽) или контур заказчика.
- **Роли и вход.** OIDC, для госслужащих — ЕСИА. Роль берётся только из токена.
- **Журнал.** Только добавление. Голова цепочки ежедневно подписывается УКЭП (ГОСТ Р 34.10-2012) или получает метку времени.
- **Персональные данные.** Метаданные фото удаляются из копий. Оригиналы хранятся с ограниченным доступом весь срок хранения. Согласие жителя.
- **Работа без сети.** Приложение подрядчика копит события и отправляет при связи. Порядок восстанавливается по хешам.
- **Производительность.** 50 тыс. очагов и 1 млн событий на программу. Пересборка состояния — с кэшем снимков (snapshot) каждые 10 тыс. событий.
- **Совместимость.** Сборка под Astra Linux и РЕД ОС. Открытые форматы: GeoJSON, GeoParquet, CSV.
- **Объяснимость.** Любое «нельзя» — со ссылкой на норму или правило системы.

## 5. Вне объёма

- Назначение штрафов.
- Опрыскивание дронами в черте населённых пунктов.
- Определение правообладателя без запроса уполномоченного органа: персональные данные ЕГРН с 2023 года без согласия не выдаются.

## 6. Метрики успеха пилота

| Метрика | Цель | Определение в коде |
|---|---|---|
| Дней от сигнала до осмотра (медиана) | ≤ 5 | `signal_to_check_days_median` |
| Доля подтверждённых кандидатов в верхнем слое | измерить, цель ≥ 30% | `sampling.binary_accuracy` |
| Приняты с первого раза | ≥ 80% | `first_pass_acceptance` |
| Заблокированные нарушения | 100% попыток в журнале | `blocked_prohibited_method` |
| Отрастание на контроль | снижение от сезона к сезону | `relapse_rate_per_followup` |
| Гербицид, л/га | −50% к прошлому сезону заказчика | `herbicide_l_per_ha` |
| Автоподтверждение фото жителей | ≥ 70% без эксперта при точности ≥ 93% | `ai_autoconfirm_share`; классификатор InvaRadar: 68,2% при 93,8% |
