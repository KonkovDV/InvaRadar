Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Коротко: уважайте участников, спорьте об аргументах, а не о людях, принимайте критику кода спокойно. Домогательства, оскорбления и раскрытие чужих личных данных недопустимы. О нарушениях пишите сопровождающим проекта через раздел Security этого репозитория; обращения рассматриваются конфиденциально.
