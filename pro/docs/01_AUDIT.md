# Гиперглубокий аудит: InvaRadar, вся наша работа и ИнваРадар Pro

Дата: 07.11.2026.

Этот файл — снимок на 07.11.2026, до коммита `9688b9d`. Пункты 5 и 6 ниже описывают наряды без юрисдикции и подрезку 5–10 см. Сейчас юрисдикция записана, подрезка 10–15 см, решение наряда пересчитывает сервер, а формулировки карты отделены от пиксельного ряда 2023/2024. Числа в таблицах этого файла не переписывались: это журнал находки, не текущее состояние.

## 1. Десять главных выводов

1. **Инженерная основа сильная.**
   - Тесты InvaRadar зелёные: в Python все прошли, 3 пропущены (нужны собранная программа ядра и полная таблица, которой нет в git); в Rust 9 из 9.
   - Инференс на Rust совпадает с LightGBM до 1,1·10⁻¹⁵.
   - Есть пространственная кросс-проверка с буфером 500 м, бутстрэп по блокам, индекс Бойса, область применимости и STAC-каталог.
   - Такую основу эксперт уважает.
2. **Главный разрыв — между картой и результатом.** Наряд InvaRadar остаётся черновиком («status: candidate», «signed_by» пусто). Кто подписал, сделано ли, вернулся ли очаг — нигде не фиксируется. Pro закрывает именно этот разрыв.
3. **«Прогноз новых очагов» пока не прогноз (К для формулировок).** Признаки и у старых, и у «новых» точек — эмбеддинг AlphaEarth 2025 года (docs/SCIENCE.md, §4). «Новые» находки 2025–2026 годов оцениваются по снимку их же года: это «сейчас-каст», не прогноз.
   - Исправление: пересчитать вариант с эмбеддингом 2023 или 2024 года; в metrics.json уже есть параметр `embedding_year`.
   - До пересчёта говорить: «41,5% новых мест золотарника — в 20% площади», без слов «предсказала заранее».
4. **Различение слабое, полевой проверки нет (В).**
   - ROC AUC против фона — 0,687 для борщевика и 0,684 для золотарника.
   - Для борщевика верхний 1% площади ловит 1,3% находок; доверительный интервал включает случайный обход.
   - Из 250 точек полевой выборки ни одна не обойдена.
   - Честная формулировка: «сужает поиск в 2–3 раза на 10–20% площади».
5. **Правовое основание неполное во всех нарядах (В).** В 200 из 200 нарядов по каждому виду юрисдикция «не определена». Пакет Московской области помечен как несверенный (`invaradar/legal.py:25`).
6. **Агротехника местами мельче лучших практик (С).**
   - Подрезка «на 5–10 см» (`invaradar/management.py:312`, `:314`). Руководства дают 10–25 см: обзор Conservation Evidence по Giant Hogweed Best Practice Manual — 10–25 см; Metro Vancouver — 5–15 см; шотландские рекомендации — около 15 см.
   - Нет правил гигиены: срезанные зонтики дозревают, грунт и техника переносят семена.
7. **Дрон — вне закона о полётах.** С 20.06.2026 полёты запрещены над Москвой и большей частью области. Цель «полнота дрона ≥ 90%» из плана пилота недостижима как основа. Подтверждать придётся бригадам, жителям и спутнику.
8. **Главный риск топ-10 — не технология, а люди и деньги.** Сейчас один автор, писем о партнёрстве нет (docs/PLAN.md). Расчёт: без пилота с измеренным результатом к маю вероятность топ-10 падает на 17,5 п. п.
9. **В наших прежних документах есть неточности, их надо исправить до подачи:**
   - в сценарии демо сказано «модель училась на данных до 2024 г.»;
   - живая съёмка экрана членом жюри провалит проверку места;
   - топ-10 в модели v2 считался грубой формулой.
10. **У Pro свои честные ограничения:**
    - события 2027–2030 годов, линии, пригодность и ответы полевой выборки в демо синтетические;
    - EXIF можно подделать;
    - доля дальнего заноса на синтетике определяется плохо (0,90 и 0,25 при истине 0,75);
    - вход по заголовкам в API — только для демо.
