# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.2.0] — 2026-10-30

### Добавлено
- Модуль БПЛА на реальных снимках: замороженный DINOv2 ViT-S/14 (Apache-2.0) + линейный классификатор с окрестностью 3 × 3 (`DinoProbeSegmenter`); проверка на 263 аэрофото Подмосковья из открытого набора Сколтеха с исключением целой камеры — ROC AUC 0,948, Dice 0,71 (`scripts/drone_benchmark.py`, `make drone`, `outputs/drone/`).
- `tests/test_legal_invariants.py`: 12 проверок закона и согласованности чисел на опубликованных нарядах и данных веб-карты.
- `docs/EXPERIMENTS.md` — журнал экспериментов и решений; `docs/LANDSCAPE.md` — аналоги, открытый код и SOTA 2026.
- Опциональные зависимости `.[drone]`.

### Изменено
- Презентации: фото вставляются с исходными пропорциями (обрезка вместо растяжения), ссылки на веб-карту и видео, числа модуля БПЛА и классификатора фото (точность и полнота раздельно).
- Версии пакета, ядра, каталога STAC и CITATION — 1.2.0.
- README на русском и английском.

### Исправлено
- На Windows ядро называется `invaradar_core.exe`. Путь общий: `invaradar.config.core_binary`.
- Длина реки на слиянии: общий исток входит в обе ветви, короткое русло не становится главным. Очереди и карта в репозитории — расчёт 30 октября 2026 года; совместить их с кодом можно командой `make requeue`.

## [1.1.0] — 2026-10-30

### Изменено
- Правила работ: в водоохранных зонах — только механические методы (ВК РФ ст. 65 ч. 15 п. 3 и 6; СанПиН 2.1.3684-21 п. 273); для беспилотников — 700 м до населённых пунктов, вод и ООПТ по СанПиН п. 282 в редакции от 12.02.2026; в населённых пунктах — наземная обработка (п. 273); на территориях школ и детских садов пестициды не применяются (п. 273).
- Один слой детских объектов для очереди и для нарядов (`invaradar/layers.py`).
- Крупные очаги борщевика (от 0,5 га): многократный покос, подрезка корневой шейки — на краях и в малых куртинах.

### Добавлено
- `scripts/requeue.py`, `scripts/prescribe.py`, `scripts/make_release.py`; `invaradar/inat_api.py`; слой границ населённых пунктов Overture.
- Презентация для подачи по Положению о премии: 10 страниц A4 (`presentation/build_submission.js`, данные команды — `presentation/team.json`).
- Интерактивная веб-карта очагов с нарядами для GitHub Pages (`web/`, данные — `scripts/export_web.py`).

## [1.0.0] — 2026-10-29

### Добавлено
- Гидрологически корректный рельеф: заполнение понижений Priority-Flood, сток D8, TWI и HAND в Rust-ядре; кэш рельефа.
- Водоохранные зоны по ВК РФ ст. 65 (50 / 100 / 200 м по длине реки) с восстановлением длины по направленной сети водотоков.
- Правила СанПиН 2.1.3684-21 для авиаобработки; оповещение жителей в нарядах.
- Доверительные интервалы метрик (`scripts/uncertainty.py`): кластерный бутстрэп по блокам 5 км и интервал Уилсона.
- Cloud Optimized GeoTIFF и GeoParquet на выходе, каталог STAC для ассетов релиза.
- Модульные тесты Rust (6) и Python (12), CI на GitHub Actions, Dockerfile, devcontainer.
- Научные рисунки: HAND и TWI, область применимости, схема полевой выборки, выход модуля БПЛА.
- Презентация PowerPoint с заметками докладчика; генератор берёт числа из `outputs/*.json`.

### Изменено
- Область применимости модели считается как в CAST (Meyer & Pebesma 2021).
- 2-opt в маршруте может разворачивать хвост открытого маршрута.
- Пути к данным задаются переменными окружения.

### Удалено
- Первая версия пайплайна на Python (`features.py`, `model.py`, `context.py`, `train_detect.py`, `predict_map.py`, `make_queue.py`), заменённая Rust-ядром.
- HTML-версия презентации.

## [0.1.0] — 2026-10-29

- Первый расчёт: эмбеддинги AlphaEarth, признаки и инференс на Rust, карты борщевика и золотарника по Москве, очередь и маршрут, модуль БПЛА, проверка фото.
