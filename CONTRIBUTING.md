# Как помочь проекту

Спасибо, что хотите улучшить ИнваРадар. Больше всего проекту нужны полевые данные: если вы проверили очаг с карты на месте, заведите issue по шаблону «Полевая проверка» — это лучшая разметка для следующего сезона.

## Код

1. Сделайте форк и ветку от `main`.
2. Установите окружение: `pip install -e ".[dev]"`, `cd core-rs && cargo build --release`.
3. Перед коммитом: `make lint test` (или `pre-commit run --all-files`).
4. Если изменились модель или признаки, пересчитайте карту (`make all`) и опишите в PR, как изменились `outputs/*/metrics.json` и `uncertainty.json`. Если изменились только правила обработки или слои контекста, достаточно `make requeue`: очереди, наряды и веб-карта, без нового обучения.

## Правила

- Метрики считаются шахматкой блоков 5 км с полосой 500 м вокруг проверочных находок и разрезом по году метки на одном снимке AlphaEarth (новизна дальше 500 м). Случайное разбиение не принимается. Опубликованные числа в `outputs/` вручную не правятся.
- Каждое правило обработки ссылается на норму или помечено как правило осторожности.
- Данные и фото — только под открытыми лицензиями, с указанием авторов.
- Новые зависимости — с открытой лицензией, совместимой с Apache-2.0.
