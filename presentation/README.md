## Дизайн

- **Фирменный стиль заказчика.** Палитра снята с CSS сайта Экологической премии Москвы (ecopremia.moscow): изумрудный `#00906A`, мятный `#2CA982`, фиолетовый акцент кнопок `#8968AA`, текст `#454545`. Скругления карточек и «таблетки» навигации — как на сайте. Логотипы и гербы города не используются: презентацию подаёт команда, а не ведомство.
- **Цвета данных:** ржавый — борщевик, золотой — золотарник, синий — вода; они совпадают с картами из `outputs/figures`.
- **Шрифты.** Подача — только Arial (требование конкурса). Полная версия — Montserrat в заголовках и крупных числах, Golos Text в тексте, Literata в латинских названиях видов и формулах (в Montserrat нет греческих букв).
- **Фоны** `brand_cover.png` и `brand_light.jpg` нарисованы процедурно в той же палитре (`brand_assets.py`): мягкие «ленты», как на главной сайта премии.
- **Живая карта.** На обложках обеих версий и на слайде «Запрос» — QR-код веб-карты с приоритетными очагами и нарядами; ссылки в PDF кликабельны.
- **Настоящий наряд.** Стр. 9 подачи и слайд 16 показывают строку из опубликованной очереди: генератор сам выбирает первый наряд, где сработали сразу три правила (водоохранная зона, дети рядом, парк).
- **Реальные программы и OSINT.** Слайд 19 — Дания, Латвия, Петербург («Городовой») и Подмосковье; слайд 32 — что в 2026 году доступно Москве со спутника, с дрона и пешком (ограничения Росавиации, платность ДЗЗ по 89-ФЗ, плановые осмотры «Контроля Москвы»).
- **Штраф — крайняя мера.** Слайд 21 показывает воронку «кандидаты → подтверждены → предписания → убраны без штрафа → штрафы» в трёх сценариях; доли — допущения до полевой проверки, считаются в генераторе из `enrich_summary.json`.
- **Дрон без чужих снимков.** Аэрофото Сколтеха без лицензии в комплект не входят. Слайд 7 показывает схему патчей DINOv2 на открытом фото iNaturalist (`make_drone_scheme.py`), подача — три проверочных числа модуля БПЛА.
- **Графики** — нативные графики PowerPoint, их можно править и проверять по данным.
- **Типографика** — неразрывные пробелы после коротких предлогов, между числом и единицей, перед тире и после «ст.», «п.», «№» ставятся автоматически (функция `typo` в обоих генераторах).

## Пересборка

```bash
cd presentation
npm ci
bash fonts/install_fonts.sh        # Windows: fonts/install_fonts_windows.ps1
npm run brand                      # фирменные фоны и схема патчей дрона
npm run icons                      # иконки в фирменных цветах (нужен Playwright)
npm run all                        # обе презентации → PDF → проверки qa/
python export_notes.py InvaRadar_Ecopremia2026.pptx SPEAKER_NOTES.md
```

Числа берутся из `outputs/*.json` и `outputs/heracleum/work_orders_top200_2025.csv`, контакты — из `team.json`. Для PDF нужен LibreOffice; чтобы в PDF подачи был настоящий Arial, а не метрически совместимый Liberation Sans, Arial должен быть установлен в системе.

`npm run qa` возвращает ненулевой код, если какой-то символ набран шрифтом, где его нет, или если слова разных строк наезжают друг на друга. Перед загрузкой на сайт премии обе проверки должны показать «проблем 0».

## Перед подачей

1. Заполнить `team.json`: ФИО всех участников, телефон, e-mail, ссылку на видео.
2. `npm run all`, затем просмотреть PDF глазами.
3. На ecopremia.moscow загрузить `InvaRadar_Ecopremia2026_10.pdf` и скан подписанного согласия на обработку персональных данных каждого участника.
