## 2. Живое демо на сцене (команды)

Всё работает без сети. Время — около 2 минут.

1. **Проверка.**
   ```bash
   make test
   ```
   49 тестов Pro зелёные. Фраза: «Закон проверяется тестами: у воды нет химии, у детей нет пестицидов, у памятника нет перекопки».
2. **Демо.**
   ```bash
   make demo
   ```
   Показать `out_demo/story.md`:
   - агент попросил утвердить наряд — нужна подпись человека;
   - химия у воды заблокирована дважды: точечная и штанговая;
   - область и городская ООПТ ждут юриста, демо не называет их Москвой;
   - первая сдача ранга 6 возвращена, затем рецидив, очаг остаётся под контролем;
   - ранг 1 закрыт.
3. **Паспорт очага** `out_demo/passports/HER-2025-001.md`: закон со ссылками и журнал с хешами.
4. **Подделка журнала.** Исправить в `events.jsonl` любую букву исполнителя:
   ```bash
   make verify
   ```
   Ответ: «цепочка нарушена на событии N».
5. **Распознавание вида** — живое. Фото растения из зала идёт в классификатор InvaRadar.
6. **Формальная проверка права.**
   ```bash
   make lawcheck
   ```
   «177 147 сочетаний на связанной сетке, свойства выполнены. Три расстояния 700 м ходят вместе». Фраза: «Неизвестное никогда не разрешает того, что известное могло бы запретить».
7. **Доказательство для подрядчика.**
   ```bash
   invaradar-pro prove out_demo/events.jsonl --seq 42
   ```
   7 хешей вместо всего журнала. Если цепочка уже сломана, prove отвечает отказом и доказательство не печатает.

Проверку доказательств на сцене не делаем: в фото будет GPS зала, и проверка места провалится. Для неё — подготовленные полевые фото.

3. **Решение:** 5 звеньев от сигнала до закрытия.
4. **Демо-скриншоты:** паспорт, блокировка, «до/после».
