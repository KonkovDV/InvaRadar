# Безопасность

Сообщайте об уязвимостях через GitHub Security Advisories (вкладка Security → Report a vulnerability), а не в открытых issue. Мы ответим в течение 7 дней.

Особое внимание: персональные данные жителей. Бот и API не должны сохранять лица, номера машин и геометки жилых адресов; в модели хранятся только координаты очагов (152-ФЗ).
