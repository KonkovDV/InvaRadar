# ИнваРадар Pro

От сигнала до устранённого очага борщевика и золотарника:
- закон в наряде;
- доказательство работ;
- контроль пяти сезонов;
- аудит коридоров ЛЭП и дорог.

Pro — слой исполнения поверх карты [InvaRadar](https://github.com/KonkovDV/InvaRadar). В этом репозитории пакет лежит в каталоге `pro/`. Связь с картой — в UPSTREAM.md.

- суть и смысл — `docs/00_SUT_I_SMYSL.md`;
- аудит — `docs/01_AUDIT.md`;
- путь в топ-10 «Академии инноваторов» — `docs/07_TOP10_PLAN.md`;
- SOTA 2026 — `docs/08_SOTA_2026.md`;
- мировые кейсы «от и до» — `docs/09_WORLD_CASES.md`;
- научный отчёт — `docs/10_WHITE_PAPER.md`;

## Быстрый старт

Нужны Python 3.11+, numpy, PyYAML и Pillow. API (необязательно) требует FastAPI.

```bash
pip install -e ".[dev]"
```

```bash
make test
```

```bash
make demo
```

Без установки:

```bash
PYTHONPATH=src python -m invaradar_pro demo --out out_demo
```

Демо работает 2 секунды и без сети. Что оно делает:
- берёт 8 реальных очагов из нарядов InvaRadar 2025 года;
- проводит их через синтетические события 2027–2030 годов;
- пишет в `out_demo/` журнал, паспорта очагов, KPI, аудит коридоров, прогноз и план полевой выборки.

## Команды

| Команда | Что делает |
|---|---|
| `invaradar-pro demo` | Сквозное демо |
| `invaradar-pro verify out_demo/events.jsonl` | Проверка цепочки хешей журнала |
| `invaradar-pro prove out_demo/events.jsonl --seq 5` | Доказательство включения события в журнал (RFC 9162) |
| `invaradar-pro law --csv data/sample/heracleum_work_orders_top200_2025.csv --rank 1 --jurisdiction moscow_city` | Решение по закону для очага |
| `invaradar-pro consistency --csv data/sample/heracleum_work_orders_top200_2025.csv` | Сверка инвариантов права с нарядами InvaRadar |
| `invaradar-pro corridor --lines lines.geojson --csv ...` | Аудит линий по километрам |
| `invaradar-pro tools` | Описания инструментов для ИИ-агента |
| `uvicorn invaradar_pro.api:app` | HTTP API (демо-режим ролей через заголовки) |
| `python analysis/top10_path.py` | Расчёт вероятности топ-10 по уровням трекшна |

## Структура

```
src/invaradar_pro/
  law.py, rules/*.yaml     закон как код: методы, нормы, юрисдикции
  workflow.py              состояния очага, проверки переходов, подпись человека
  events.py                журнал с цепочкой хешей
  merkle.py                дерево Меркла RFC 9162: доказательства включения и согласованности
  eradication.py           байесовское закрытие очага и оптимальная остановка (Regan et al., 2006)
  validation.py            честный ретро-прогноз, блочный бутстрэп, диагностика NNDM
  law_check.py             формальная проверка права на связанной сетке (177 147 контекстов)
  power.py                 мощность и объём выборки для предрегистрированных исследований
  evidence.py              проверка фото: место, время, повторы, «до/после», спутник
  spread.py                прогноз появления новых очагов (2Dt + коридоры, БПФ)
  corridor.py              аудит охранных зон ЛЭП и полос дорог (ПП РФ № 160)
  calibration.py           изотоническая калибровка, польза выезда
  sampling.py              полевая выборка Olofsson, Нейман, Уилсон
  kpi.py, report.py        показатели и паспорта очагов
  agent_tools.py, api.py   инструменты ИИ-агента (с подписью человека), FastAPI
  upstream.py, demo.py, cli.py
tests/                     49 тестов
data/sample/               наряды InvaRadar top-200 (оба вида), полевая выборка (CC BY 4.0)
docs/                      суть, аудит, PRD, архитектура, право, наука, рынок, план топ-10, SOTA 2026, мировые кейсы, научный отчёт, предрегистрация
application/               заявка, питчдек по 15 пунктам, видео и демо, вопросы и ответы, работа с заказчиками
analysis/                  путь в топ-10, бенчмарк фото, воспроизводимость; realdata/ — ретро-прогноз на реальных данных; results/ — все числа
out_demo/                  результат демо (можно пересоздать)
```

## Статус (07.11.2026, версия 0.3)

**Готово (MVP):**
- закон как код;
- процесс с подписью человека;
- журнал;
- проверка доказательств;
- контроль сезонов;
- коридоры;
- прогноз;
- выборка;
- KPI;
- API;
- журнал прозрачности RFC 9162;
- байесовское закрытие очага;
- инструменты ретро-прогноза;
- демо;
- формальная проверка права полным перебором;
- двухступенчатая проверка повторов фото (dHash + pHash) по бенчмарку на реальных снимках;
- ретро-прогноз на реальных данных (iNaturalist + AlphaEarth);
- 49 тестов;
- 0 нарушений инвариантов на 400 нарядах InvaRadar.

**Не готово:**
- бот для жителей;
- приложение подрядчика;
- веб-интерфейс;
- интеграции с «Доброделом» и «Нашим городом»;
- полевая проверка;
- ретро-прогноз без утечки;
- сверка пакета Московской области.

Синтетикой в демо являются события 2027–2030 годов, линии, поле пригодности и ответы выборки.
